12.1- Understanding Various Mobile Device Connection Methods: 
 
Mobile Device Connection Methods:


### Slide / Page 497

è Near- Field Communication (NFC): Electromagnetic Induction within a range of 10 cm 
 
è Satellite Communication (Satcom): Artificial Geostationary Satellite for global service (slow and 
expensive) 
 
è Cellular Communication: Single network tower that servers devices within a limited radius 
 
è Adaptive Network Technology (ANT): Wireless sensor protocol between sensors and their 
controllers 
 
è Universal Serial Bus (USB): Wired communication for devices 
 
è Global Positioning System (GPS): Radio navigation and positioning system based on satellite 
 
è Infrared (IR): Wireless Technology for transferring digital data within a short range of up to 5m 
 
 
è Wi-FI, Bluetooth, 5G Cellular (Mobile Communication)

Mobile Device Management (MDM)


### Slide / Page 498

à Platforms that provide for all types of devices for management to grant admins to control and secure

organizational devices 
 
è Mobile Security Management: Implements actions and precautionary steps for security 
 
è Remote Wipe: A technique used for encrypting data from miscreants. Allows a command to erase

è Geolocation: Provides real-world geographical location


### Slide / Page 499

è Geofencing: Virtual fence at a specific location that interacts with mobile users; this allows 
marketers to gather sensitive data and information about users’ offline activities from the location 
data 
 
è Full Device Encryption: Encrypts all information stored on any storage medium within a device 
 
è Containerization: Technique where all personal and organizational data are segregated on an 
employee’s device. Helps improve security of organizational of data. 
 
è Over-the-Air (OTA) Updates: Delivers updates for applications, frameware, and time zone rules… 
many more to a mobile device
