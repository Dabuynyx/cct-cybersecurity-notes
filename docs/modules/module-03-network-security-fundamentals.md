### Slide / Page 156

A secured and robust network can be designed with proper implementation and 
configuration of network security elements 
 
Network security elements: 
 
1. Network Security Controls: Minimizing access issues, counter measures, safeguards, 
encryption  
 
2. Network Security Protocols: Sets of rules and arrangement that controls how data is 
transmitted and received over a network securely.  
 
3. Network Security Devices: Hardware or software components designed to enchance 
network security such as firewalls, IDS, IPS, Antivirus Software, NAC.


### Slide / Page 157

Goal of Network Defence: To Protect the system and prevent breaches from occurring and 
prevent data loss and money loss. 
 
Organzaitons rely on information assurance (IA) principles to achieve defense-in-depth 
security 
 
IA principles act as enablers for an organization’s security activites to protect and defend 
the network from attacks. 
 
 
IA Principles: Confidentiality, Integrity, Availability 
 
Network Defence Benefits: Protect, Comply, Ensure, Reduce, Gain
