### Slide / Page 265

Warning Signs are used to warn individuals to ensure no one unknowingly intrudes any 
restricted areas. 
 
Appropriate warning signs should be placed at each access control point 
 
 
Alarm/Sensor System 
 
Alarm systems should be installed inside and at the entrance to report intrusions, 
suspicious activity and emergencies. 
 
Alarm system should be able to be turned on automatically or manually by sensor detectors 
or security personnel. 
 
Alarm system should be audible to everyone in the building and have a set time interval.
